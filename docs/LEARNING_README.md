# CSLounge Deep Learning Log

This file is the slow-pass companion to CSLounge development.

The project itself is built quickly through learning-by-doing. This log exists for deliberate backtracking: review what was added, trace how data moves through the system, understand why each layer exists, and connect the code to transferable software-engineering concepts.

## How to use this file

Read the newest entry at the end of each week. Do not try to memorize every implementation detail. Focus on being able to explain the major request/data flows and why the code is structured the way it is.

Each weekly entry should cover:

- What changed in CSLounge that week
- The end-to-end data/request flow for each major feature
- What each important file/class/component is responsible for
- The important code constructs and why they are used
- Spring Boot, Next.js, React, TypeScript, PostgreSQL, HTTP, security, Git, or architecture concepts introduced
- Common misconceptions and mistakes worth avoiding
- How the new code relates to concepts already learned
- A short "Can I explain this?" review section
- A small set of code-reading questions, without turning the review into another coding assignment
